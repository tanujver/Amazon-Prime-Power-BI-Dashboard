Amazon Prime Content Analysis Dashboard

Project Overview

This project analyzes Amazon Prime content using Power BI. The dashboard provides insights into content distribution, IMDb ratings, release trends, genres, runtime, and country-wise content availability.

Objective

The objective of this project is to explore Amazon Prime's content library and identify trends in content type, ratings, genres, and production countries.

Tools Used

- Power BI
- Microsoft Excel / CSV Dataset
- Data Visualization

Dataset

Dataset Used: Amazon Prime Titles Dataset

Key Columns:

- Title
- Type
- Release Year
- Genres
- Production Countries
- IMDb Score
- Runtime

Key Performance Indicators (KPIs)

- Total Titles
- Total Movies
- Total TV Shows
- Average IMDb Score

Dashboard Insights

- Content distribution by genre
- Average IMDb score by content type
- Content released by year
- Top countries by content count
- Average runtime by content type
- Top rated content
